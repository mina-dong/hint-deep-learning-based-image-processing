# 2일차 6교시 실습 · 프레임 차이와 변화 영역

연결 강의자료: 2일차 / 6교시.pdf

## 시작하기

1. `6교시.zip` 전체를 별도의 `6교시` 폴더에 압축 해제합니다.
2. 압축을 푼 폴더에서 Jupyter Notebook 또는 JupyterLab으로 `실습.ipynb`를 엽니다.
3. 강의자료 PDF의 해당 쪽을 보며 빈칸을 채우고, 준비 셀부터 위에서 아래로 실행합니다.
4. `images`, `samples`, `data` 폴더와 `.py` 보조 파일은 제공된 이름과 위치를 유지합니다. 교시에 따라 포함 파일이 다릅니다.

## 실행 환경

검증 환경은 Python 3.11, OpenCV 4.9.0, NumPy 1.26.4, Matplotlib 3.8.0입니다. 로컬 Jupyter 환경을 사용합니다.
필요 패키지가 없는 경우 이 폴더에서 `python -m pip install -r requirements.txt`를 실행합니다. Jupyter가 없으면 `python -m pip install notebook`으로 설치한 뒤 `python -m notebook`으로 실행합니다.

## 교시별 안내

# 6교시 실행 안내

1. ZIP 전체를 압축 해제합니다.
2. Python에 필요한 패키지를 설치합니다: `python -m pip install opencv-python numpy matplotlib notebook`
3. 압축을 푼 폴더에서 Jupyter Notebook을 열고 학생용 ipynb를 실행합니다.
4. A·B 두 빈칸을 강의자료 PDF 4·5페이지에서 확인해 채우고, 셀을 위에서 아래로 실행합니다.

제공 이미지·영상 실습은 카메라 없이 실행됩니다. 이미지와 clip.avi를 포함했습니다. 영상 셀은 outputs 폴더에 비교 이미지 3장과 changes.avi를 저장합니다. AVI 재생이 지원되지 않는 플레이어에서는 함께 저장된 PNG로 결과를 확인할 수 있습니다.

USB 카메라는 마지막 카메라 셀입니다. 로컬 GUI 환경과 카메라 접근 권한이 필요합니다. 실제 카메라 연결 실행은 검증하지 않았습니다. 정답 코드와 파일 입출력은 OpenCV 4.9.0에서 확인했습니다.

mark_changes, process_video, run_camera는 제공 함수입니다. OpenCV 내장 함수는 cv2 접두어로 구분합니다. 답안은 교수자용 자료로 별도 제공합니다.
