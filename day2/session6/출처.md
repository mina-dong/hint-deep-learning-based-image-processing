# 출처 및 처리 조건

- 실제 영상: OpenCV samples/data/vtest.avi, https://github.com/opencv/opencv/blob/4.13.0/samples/data/vtest.avi
- 5교시 공 영상: https://github.com/jonathanfoster/ball-tracking/blob/master/ball_tracking_example.mp4
- absdiff 공식 문서: https://docs.opencv.org/4.13.0/d2/de8/group__core__array.html
- threshold 공식 문서: https://docs.opencv.org/4.13.0/d7/d4d/tutorial_py_thresholding.html

기본 영상은 로컬에 확보된 OpenCV 예제 vtest.avi를 사용했습니다. 795프레임, 768×576, 파일 보고 FPS 10입니다. 공식 링크는 자료 출처이며 로컬 파일과 특정 태그 파일의 바이너리 동일성을 검증했다는 뜻은 아닙니다. 공개 자료를 자체 촬영물로 표시하지 않습니다. 별도 공 영상의 이용 허락 범위는 확인하지 않았습니다.

기본 ROI는 원본 x230:450, y140:350이며 220×210입니다. 기준 프레임은 0부터 센 459·460입니다. BGR2GRAY 후 absdiff, THRESH_BINARY의 T=20을 적용했습니다. 차이 D가 T를 초과할 때만 255로 선택합니다. 기본 필터와 Morphology는 없습니다. 차이 영상은 0~255로 표시하며 개별 정규화를 하지 않았습니다.

2페이지 측정점 (141,115)은 설명을 위해 수동 지정했습니다. 실제 Gray 값은 이전225·현재0입니다. 3페이지의 80·120·83은 설명용 숫자입니다.

7페이지의 ①·②는 이전 다리와 현재 발의 대응 위치를 수동 표시한 설명 표식이며 자동 검출 결과가 아닙니다.

9페이지 이미지는 기본 ROI 내부 x40:180, y50:175를 공통 확대했습니다. 표시된 선택 픽셀 수는 확대 전 기본 ROI 전체의 값입니다.

6페이지 기준값10/20/40 비교, 9페이지 실제 걷기400·제자리410·다시걷기460 비교는 동일 ROI입니다. 제자리에서도 작은 몸동작과 압축 등 영상 변화가 남아 완전한 0이 아닙니다.

10페이지는 원본 Frame460 BGR 배열을 int16로 바꿔 각 값에30을 더하고 0~255로 제한한 후 uint8로 변환했습니다. 실제 조명 변화 촬영이 아닙니다. 11페이지는 원본 전체를 오른쪽4pixel 이동한 후 동일 ROI를 추출했습니다. ROI에 새로 생긴 이미지 테두리는 없습니다. 실제 카메라 이동 실험이 아닙니다.

12페이지에서만 Closing3×3 1회, RETR_EXTERNAL/CHAIN_APPROX_SIMPLE, Contour면적30pixel² 이상을 사용합니다. 상자는 변화 영역의 위치와 크기이며 물체 수나 정확한 물체 전체 위치를 보장하지 않습니다.

13페이지는 5교시 공 영상 Frame49·50, ROI x300:900 y20:500입니다. 녹색범위 H35~85,S80~255,V60~255, 프레임차이T20을 사용합니다. 손과 얼굴의 변화도 포함됩니다.

15페이지는 현재460을 고정하고459·450과 비교합니다. 간격1·10프레임의 픽셀 수를 이동 속도로 해석하지 않습니다. 16페이지만 ROI를 x230:370,y140:350(140×210)으로 좁혀 기준350·현재410·직전409를 비교합니다. 기준 사진에 해당 대상이 없는 구간을 사용했습니다.

포함 clip.avi는 원본350~470 총121프레임의 기본 ROI를 FFV1 무손실10FPS로 저장했습니다. 파일 내110번이 원본460번입니다. 번호가 가리키는 좌표와 프레임 기준을 변경하지 않습니다.
