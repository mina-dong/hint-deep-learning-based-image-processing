# 출처와 가공 조건

- 사진: scikit-image coins. https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.coins
- Canny: https://docs.opencv.org/4.13.0/da/d22/tutorial_py_canny.html
- Sobel: https://docs.opencv.org/4.13.0/d2/d2c/tutorial_sobel_derivatives.html
- 원본은 1교시 제공 파일과 동일한 coins.png이며 크기는 높이303×너비384이다.
- 전체 원본에 GaussianBlur (5,5), sigmaX=1.0을 명시적으로 적용한다.
- Sobel은 CV_32F, ksize=3. 가로·세로 표시 모두 abs(계산값)/600*255를 clip,rint,uint8로 변환한다. 계산값과 표시값을 구별한다.
- Canny는 apertureSize=3, L2gradient=True. 기준50/100, low비교20/100·80/100, high비교50/80·50/160이다.
- 전체 처리 후 일반 표시 x0:190,y150:303, 확대 x10:78,y162:228을 자른다. 좌표 끝값은 포함하지 않는다.
- 2쪽 사진과 수치는 모두 전처리한 prepared를 사용한다. 측정값은 prepared[y196,x17:27]이며 x좌표 순서대로 표시한다. 사진의 안내선은 관찰 위치를 수동 표시한 것이다.
- 3·4·7·8·9·10쪽 숫자는 원리 설명용이며 사진 측정값이 아니다. 7쪽3·4·5는Gradient 크기 계산 예시이다. 10쪽은8방향 연결을 표현한 픽셀 격자이다. 설명 도식은 Canny에서 반환한 중간 영상이 아니다.
- 16쪽 가공본은 rint(0.5*gray+64),clip,uint8이다. 같은 전처리 후 Canny50/100과25/50을 비교한다. 실제 다른 조명에서 촬영한 사진이 아니다.
- 실행 환경: OpenCV4.9.0. 답안 실행과 슬라이드 이미지의 픽셀 일치를 확인했다.
