# 2일차 2교시 실습 · 경계 검출

연결 강의자료: 2일차 / 2교시.pdf

## 시작하기

1. `2교시.zip` 전체를 별도의 `2교시` 폴더에 압축 해제합니다.
2. 압축을 푼 폴더에서 Jupyter Notebook 또는 JupyterLab으로 `실습.ipynb`를 엽니다.
3. 강의자료 PDF의 해당 쪽을 보며 빈칸을 채우고, 준비 셀부터 위에서 아래로 실행합니다.
4. `images`, `samples`, `data` 폴더와 `.py` 보조 파일은 제공된 이름과 위치를 유지합니다. 교시에 따라 포함 파일이 다릅니다.

## 실행 환경

검증 환경은 Python 3.11, OpenCV 4.9.0, NumPy 1.26.4, Matplotlib 3.8.0입니다. 로컬 Jupyter 환경을 사용합니다.
필요 패키지가 없는 경우 이 폴더에서 `python -m pip install -r requirements.txt`를 실행합니다. Jupyter가 없으면 `python -m pip install notebook`으로 설치한 뒤 `python -m notebook`으로 실행합니다.

## 교시별 안내

# 2교시 실습

1. 압축 전체를 풀어 images 폴더와 노트북을 함께 둡니다.
2. Jupyter에서 노트북을 열고 위에서부터 실행합니다.
3. 강의자료 PDF 11~13쪽을 보고 빈칸 3개를 채웁니다.
4. 저장 이미지는 results 폴더에서 확인합니다.

필요 패키지: opencv-python, numpy, matplotlib. 검증 환경: OpenCV 4.9.0. Windows 이외 환경에서는 설치된 한글 글꼴로 font.family를 변경합니다.
사진: scikit-image coins. https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.coins
