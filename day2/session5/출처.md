# 출처와 가공 조건

- 공 영상: https://github.com/jonathanfoster/ball-tracking/blob/master/ball_tracking_example.mp4
- 다운로드 원본: https://raw.githubusercontent.com/jonathanfoster/ball-tracking/master/ball_tracking_example.mp4
- 사탕 사진: https://github.com/opencv/opencv/blob/4.13.0/samples/data/smarties.png
- HSV 공식 문서: https://docs.opencv.org/4.13.0/df/d9d/tutorial_py_colorspaces.html

확인일: 2026-09-28. 공개 접근 가능한 예제 자료이며 자체 촬영물로 표시하지 않습니다. 공 영상의 별도 이용 허락 범위는 확인하지 않았으므로 공개 배포 시 원 출처의 이용 조건을 확인해야 합니다.

공 영상은 1152×640, 30 FPS, 총 1137프레임입니다. 기본 사진은 0부터 센 원본 Frame 50에서 x=300:900, y=20:500을 자른 600×480 영상입니다. 제공 clip.avi는 원본 Frame 40~240의 같은 ROI를 FFV1 무손실로 저장했습니다. 세 비교 프레임에는 동일 범위를 적용했습니다.

기본 범위는 H 35~85, S 80~255, V 60~255이며 경계값을 포함합니다. uint8 HSV 표기는 H 0~179, S와 V 0~255입니다. 채널 비교는 해당 범위만 변경했습니다. 마스크에 Morphology를 추가하지 않았습니다.

후보는 RETR_EXTERNAL, CHAIN_APPROX_SIMPLE, contourArea ≥ 300 pixel²로 구하고 boundingRect를 적용했습니다. 사탕 사진에서는 작은 입력 크기에 맞춰 최소 면적 100 pixel²를 사용했습니다. contourArea와 선택 픽셀 개수는 다른 측정값입니다. 빨간 상자는 검출 결과 표시색입니다.

밝기 가공은 BGR 배열을 float32로 변환해 0.35배하고 0~255로 제한한 뒤 uint8로 변환한 결과입니다. 실제 노출·조명을 바꾼 촬영 결과가 아닙니다. 3개 측정 지점 위치는 설명을 위해 수동 지정한 좌표이며 자동 검출 결과가 아닙니다.

전체 16페이지 권장 운영: 1~4페이지 12분, 5~6페이지 8분, 7~9페이지 12분, 10~12페이지 10분, 13~14페이지 실습 12분, 15~16페이지 사례 6분으로 총 60분 구성입니다. 실제 진행 시간은 질의·실습 속도에 따라 달라집니다.
