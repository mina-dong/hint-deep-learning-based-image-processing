# 2일차 5교시 실습 · HSV 기반 색상 객체 검출

연결 강의자료: 2일차 / 5교시.pdf

## 시작하기

1. `5교시.zip` 전체를 별도의 `5교시` 폴더에 압축 해제합니다.
2. 압축을 푼 폴더에서 Jupyter Notebook 또는 JupyterLab으로 `실습.ipynb`를 엽니다.
3. 강의자료 PDF의 해당 쪽을 보며 빈칸을 채우고, 준비 셀부터 위에서 아래로 실행합니다.
4. `images`, `samples`, `data` 폴더와 `.py` 보조 파일은 제공된 이름과 위치를 유지합니다. 교시에 따라 포함 파일이 다릅니다.

## 실행 환경

검증 환경은 Python 3.11, OpenCV 4.9.0, NumPy 1.26.4, Matplotlib 3.8.0입니다. 로컬 Jupyter 환경을 사용합니다.
필요 패키지가 없는 경우 이 폴더에서 `python -m pip install -r requirements.txt`를 실행합니다. Jupyter가 없으면 `python -m pip install notebook`으로 설치한 뒤 `python -m notebook`으로 실행합니다.

## 교시별 안내

# 5교시 실습 실행 안내

1. ZIP 전체를 압축 해제합니다.
2. Python 환경에 opencv-python, numpy, matplotlib, notebook을 설치합니다. (`python -m pip install opencv-python numpy matplotlib notebook`)
3. 이 폴더에서 Jupyter Notebook을 열고 학생용 ipynb를 실행합니다.
4. 강의자료 PDF 5·6페이지에서 두 빈칸을 확인하고 순서대로 셀을 실행합니다.

이미지와 짧은 영상이 포함되어 카메라 없이 제공 이미지·영상 실습을 진행할 수 있습니다. USB 카메라는 마지막 카메라 셀에서 실행합니다. GUI 창을 지원하는 로컬 환경과 카메라 권한이 필요합니다. 카메라 입력·저장 API는 다시 설명하지 않습니다.

OpenCV 4.9.0에서 정답 코드와 제공 영상을 검증했습니다. 후보 중심은 바운딩 박스의 중심이며 물체의 실제 중심을 보장하지 않습니다. 밝기 가공 입력은 원본 BGR 값을 0.35배한 결과입니다.
