# 2일차 7교시 실습 · 색상 객체 추적

연결 강의자료: 2일차 / 7교시.pdf

## 시작하기

1. `7교시.zip` 전체를 별도의 `7교시` 폴더에 압축 해제합니다.
2. 압축을 푼 폴더에서 Jupyter Notebook 또는 JupyterLab으로 `실습.ipynb`를 엽니다.
3. 강의자료 PDF의 해당 쪽을 보며 빈칸을 채우고, 준비 셀부터 위에서 아래로 실행합니다.
4. `images`, `samples`, `data` 폴더와 `.py` 보조 파일은 제공된 이름과 위치를 유지합니다. 교시에 따라 포함 파일이 다릅니다.

## 실행 환경

검증 환경은 Python 3.11, OpenCV 4.9.0, NumPy 1.26.4, Matplotlib 3.8.0입니다. 로컬 Jupyter 환경을 사용합니다.
필요 패키지가 없는 경우 이 폴더에서 `python -m pip install -r requirements.txt`를 실행합니다. Jupyter가 없으면 `python -m pip install notebook`으로 설치한 뒤 `python -m notebook`으로 실행합니다.

## 교시별 안내

# 실행 안내

ZIP 전체를 압축 해제하고 같은 폴더에서 Jupyter Notebook을 실행합니다.
필요한 패키지: `python -m pip install opencv-python numpy matplotlib notebook`

학생용 ipynb의 A·B 빈칸을 강의자료 PDF 5·7페이지에서 확인하여 채운 뒤 위에서부터 실행합니다. 답안은 교수자용 자료로 별도 제공합니다.

기본 영상과 비교 이미지를 포함했으므로 카메라가 필요하지 않습니다. 영상 출력은 outputs 폴더의 AVI와 PNG로 저장됩니다. AVI의 FFV1 코덱 재생을 지원하지 않는 플레이어에서는 PNG를 확인하거나 OpenCV로 다시 읽을 수 있습니다.

track_video, candidates, choose, overlay는 제공 함수이며 OpenCV 내장 함수가 아닙니다. 영상 기록의 frame은 클립 내부 번호입니다. 강의자료 PDF 원본 번호와의 대응은 노트북 각 절에 안내했습니다. 창 표시·카메라 연결 실습은 포함하지 않습니다.
