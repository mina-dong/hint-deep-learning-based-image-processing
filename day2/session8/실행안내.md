# 2일차 8교시 실습 · 영상 처리 시간과 FPS 측정

연결 강의자료: 2일차 / 8교시.pdf

## 시작하기

1. `8교시.zip` 전체를 별도의 `8교시` 폴더에 압축 해제합니다.
2. 압축을 푼 폴더에서 Jupyter Notebook 또는 JupyterLab으로 `실습.ipynb`를 엽니다.
3. 강의자료 PDF의 해당 쪽을 보며 빈칸을 채우고, 준비 셀부터 위에서 아래로 실행합니다.
4. `images`, `samples`, `data` 폴더와 `.py` 보조 파일은 제공된 이름과 위치를 유지합니다. 교시에 따라 포함 파일이 다릅니다.

## 실행 환경

검증 환경은 Python 3.11, OpenCV 4.9.0, NumPy 1.26.4, Matplotlib 3.8.0입니다. 로컬 Jupyter 환경을 사용합니다.
필요 패키지가 없는 경우 이 폴더에서 `python -m pip install -r requirements.txt`를 실행합니다. Jupyter가 없으면 `python -m pip install notebook`으로 설치한 뒤 `python -m notebook`으로 실행합니다.

필요 패키지는 `opencv-python`, `numpy`, `matplotlib`입니다. 화면 표시 비교에는 OpenCV 창을 띄울 수 있는 로컬 실행 환경이 필요합니다. Colab과 `opencv-python-headless` 환경에서는 표시 비교를 실행하지 못합니다. 기존 실습 환경에 설치된 패키지를 확인한 뒤 사용합니다.

## 파일

- `실습.ipynb`: 두 빈칸과 비교 실행
- `timing_helpers.py`: 영상 입력, 후보 검출, 위치 연결, 시간 기록, 결과 표시
- `practice_views.py`: 구간 그래프, 같은 영역 확대, 측정표 저장
- `data/normal.avi`: 비교할 입력 영상
- `출처.md`: 원본 출처와 가공·측정 조건

답안은 교수자용 자료로 별도 제공합니다.

## 측정값 읽기

- `s`는 초, `ms`는 밀리초이며 1초는 1000ms입니다.
- 처리 FPS는 완료한 프레임 수를 전체 경과 시간으로 나눈 값입니다.
- 입력 영상의 30FPS는 파일의 재생 기준입니다. 프로그램의 측정 FPS와 구분합니다.
- 실행마다 시간이 달라집니다. 강사 화면과 같은 수치가 나와야 하는 것은 아닙니다.
- 분석 시간은 후보 검출과 위치 연결 구간입니다. 전체 반복 시간은 읽기·크기 조절·분석·그리기·설정된 표시와 키 입력 대기를 포함합니다.
- 화면 표시 구간은 OpenCV 호출과 대기에 걸린 시간입니다. 촬영부터 실제 모니터 표시 완료까지의 지연을 측정한 값이 아닙니다.

## 표시·크기 비교

표시 비교는 같은 영상과 크기를 유지하고 화면 표시·키 입력 대기만 바꿉니다. 두 조건 모두 결과 그림을 만듭니다. 영상 크기 비교는 576×320과 288×160을 사용하며, 좌표와 면적 기준을 원래 영상 크기로 환산합니다.

노트북에서 다른 실행이 진행 중일 때 새 비교를 겹쳐 실행하지 않습니다. 측정 중 OpenCV 창을 닫으면 실행이 중단될 수 있으므로 영상 처리가 끝날 때까지 기다립니다.

실행 후 `outputs/measurements.csv`, `outputs/full.avi`, `outputs/half.avi`가 생성됩니다. 결과 영상은 두 조건 모두 576×320, 30FPS로 저장하며, 작은 크기로 검출한 좌표를 원래 크기의 화면에 표시합니다.

9페이지의 회차별 그래프는 `plot_fps`가 FPS로 출력합니다. 10페이지의 `show_sizes`는 각 크기의 대표 실행에서 검출 시간과 전체 평균 시간, FPS를 함께 보여줍니다. 두 함수는 `practice_views.py`에 제공됩니다.
